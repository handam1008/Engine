# 스탯 밸런스 기준표 (2026-11-24)

## 기준
- **기준 적: 아이챗** — 체력 100, 공격 20 / 2초(초당 피해 10), 사거리 1, 이속 2.5, 백신 10.
  CHO의 Gimp(체력 100, 초당 피해 10, 이속 3)와 같은 체급이라 리눅스 적과 맥 적이 한 척도를 공유한다.
- 단위: 이속 = 초당 유닛 수(`MoveSystem`이 그대로 velocity에 넣음). 테스트 레인 길이 약 25유닛 → 이속 2.5면 10초에 건넘.
- 사거리 단계(Unity 유닛, `OverlapCircle` 반지름): 근접 1~1.5 / 중거리 2~4.5 / 원거리 5.5~6.
- 처치 시간 = 기준 적 체력 ÷ 유닛 초당 피해. 버티는 시간 = 유닛 체력 ÷ 10.
- KB = 강함(체력 × 초당 피해, 사거리·특수능력 보정)에 비례. 1440KB 안에 5~8기 정도가 동시에 서도록 잡음.

## 코드 쪽 남은 문제 (값만으로 해결 안 됨)
1. **저장공간 제한이 없다**: `StorageService.AddStorage`가 항상 `true`. `attackStorage`는 아무 데서도 안 쓴다. KB 밸런스는 이게 작동해야 의미가 있다.
2. **강화가 SO 원본을 바꾼다**: `PowerUpManger`가 `CharacterDataSO`의 `level/maxHp/attackDmg`를 직접 올린다. 에디터에서 강화를 누르면 위 값이 영구로 바뀐다(계산기 레벨 82가 이렇게 생김). 또한 레벨당 +10 고정이라 휴지통(500)과 메모장(5×5)에 같은 +10이 붙는다 → 비율(예: +8%)로 바꾸는 게 맞다.
3. **핀볼은 피해를 안 준다**: `PinballAttackSO`는 멈춘 뒤 1초 후 자폭만 한다. `attackDmg`는 쓰이지 않음.
4. **미디어플레이어는 `attackDmg`를 안 쓴다**: 100×100 박스 안 적 전부를 3초 정지(기지 포함 여부 확인 필요).
5. **GoggiBanpae(EnemyFirstLineEnemySO)** 는 쓰는 프리팹이 없어 손대지 않음.
