# 적 전용 아트·동작 규칙

현재 기준: 2026-10-25. 이 문서는 이전 적 아트 규칙을 대체한다.

## 적용 범위 — 반드시 적(Enemy)에만 적용

- 적용 대상: 적의 외형, 적 이미지 프롬프트, 적 스프라이트와 동작.
- 적용 금지: 아군 캐릭터(Character), 아군 XP 도구·아이콘, 아군 공격 효과, XP UI·창·배경·소품. 기존 아군·UI 규칙은 유지한다.
- 프롬프트의 주체는 반드시 `ENEMY UNIT` 또는 `ENEMY CREATURE`다. 생성 대상을 모호하게 `character`라고 부르지 않는다.
- ‘아군에 얼굴·팔다리를 붙이지 않는다’는 기존 아군 규칙을 적에게 전파하지 않는다. 적에게는 단순한 얼굴이 있어야 한다.
- 이 문서는 시각과 동작 기준이다. 바이러스·와이퍼·웜·랜섬웨어·애드웨어의 기존 게임플레이 기획과 스탯은 변경하지 않는다.

## 정체성

XP 컴퓨터 안에서 손상된 데이터가 살아 움직이게 된 생물. 낮은 해상도에서도 알아보기 쉬운, 조금 엉뚱하고 성가신 침입자로 그린다.

단순한 외곽선·적은 색·짧고 과장된 동작을 사용한다. 특정 게임의 얼굴, 몸 비례, 귀, 실루엣이나 기존 적 디자인을 복사하지 않는다. 생성 프롬프트에 특정 게임명을 스타일 키워드로 넣지 않는다.

## 외형

1. **부드러운 비대칭 몸.** 콩·방울·낮고 긴 덩어리처럼 하나로 이어진 생물 몸을 기본으로 한다. 완전한 구형을 기본값으로 삼지 않는다. 모든 적에 같은 몸·발을 반복하지 않는다.
2. **실루엣에 보이는 데이터 오류 하나.** 몸 일부의 밀림, 네모난 누락 홈, 작은 몸 조각의 새어 나옴 중 하나를 주된 특징으로 삼는다. 작게 보이지 않는 표면 무늬로 대체하지 않는다.
3. **오류를 누적하지 않는다.** 밀림덩이는 상체 밀림 자체가 오류다. 추가 홈·부유 조각·글리치 무늬를 다시 붙이지 않는다. 계열 특성이 몸 구조를 결정한다면 그 구조를 주요 특징으로 삼고 추가 장식을 얹지 않는다.
4. **얼굴 필수.** 검거나 짙은 슬레이트색 점눈 두 개와, 눈보다 작은 점 입 또는 짧은 선 입을 사용한다. 눈동자·흰자·반사광·복잡한 눈썹은 추가하지 않는다. 얼굴은 몸 형태에 맞춰 앞쪽 또는 한쪽에 배치할 수 있다.
5. **발과 돌출부는 선택 사항.** 이동을 표현하기 위한 같은 양발 한 쌍을 기본으로 붙이지 않는다. 몸 밑면이 눌리거나 미끄러지는 방식도 사용한다. 새 팔다리·손·무기 없이 움직일 수 있는 구조를 우선한다.
6. **작은 화면에서 판별.** 검은 실루엣만으로도 기본형·빠른형·탱커형이 구분되어야 한다. 색과 액세서리만 바꿔 다른 적으로 만들지 않는다.

## 표현

- 기존 게임 리소스와 같은 거친 픽셀 밀도와 짙은 슬레이트색 외곽선을 사용한다. 아군 이미지는 픽셀·외곽선·색면 표현의 참고로만 쓰며, 아군의 물체 형태를 적에게 복사하지 않는다.
- 하나의 몸 재질은 대표색을 포함해 **넓은 색면 2~3단계**로 표현한다. 단순한 주색과 큰 명암면을 사용하고, 계열과 개체의 색상은 별도로 지정한다.
- 픽셀 격자를 일정하게 유지하고 확대는 최근접 보간을 사용한다. 임의의 큰 픽셀과 작은 픽셀을 뒤섞지 않는다. 정확한 격자와 알파는 결과물에서 검수한다.
- 그라데이션, 에어브러시, 광택 띠, 발광, 입체 렌더 느낌, 노이즈, 무작위 미세 하이라이트를 넣지 않는다.
- 기본 시점은 **화면 왼쪽을 향하는 2D 횡스크롤 적**이다. 얼굴이 읽히도록 약한 3/4 표현은 허용하되, 위에서 내려다보는 아이소메트릭 구도는 사용하지 않는다.
- 완성 스프라이트는 실제 투명 배경이다. 검은 배경·체커보드·바닥·그림자·설명 텍스트·스티커 테두리를 이미지에 그려 넣지 않는다. 사방에 잘림 방지 여백을 둔다.

## 제외할 디자인

- 고양이 귀와 고양이형 `ω` 미소, 흰 대칭 구형 몸과 똑같은 짧은 양발의 조합.
- 얼굴 없는 UI 오브젝트, 기계 로봇, 인간형 전사, 갑옷 입은 사람.
- 파편·금속 블록을 여러 개 쌓은 복잡한 조립체.
- 큼직한 자물쇠·달러 기호·사슬·장비를 붙이는 방식의 자동 계열 구분. 계열의 기능을 몸 구조로 먼저 표현한다.
- 프레임마다 눈 수, 몸 조각 수, 색상, 픽셀 크기, 카메라 시점이 달라지는 결과.

## 동작 공통 규칙

- 실루엣을 결정한 몸 구조로 동작을 만든다. 이동·공격을 위해 새 손발이나 도구를 추가하지 않는다.
- **대기:** 밑면 위치를 유지한 작은 압축·복원. 얼굴이 크게 흔들리거나 부품이 새로 생기지 않는다.
- **이동:** 몸이 앞쪽으로 눌리고 뒤가 따라오는 미끄러짐, 또는 낮은 몸의 압축·복원. 스프라이트 시트 자체는 제자리 동작이며 실제 전진은 게임 이동 코드가 담당한다.
- **공격:** 준비 동작 → 접촉·타격 → 반동 → 복귀 순서로 읽히게 한다. 기본 근접 적은 준비 때 뒤로 압축하고, 타격 때 앞쪽 몸덩이를 화면 왼쪽으로 뻗는다.
- **피격:** 짧은 찌그러짐이나 기울어짐. 이동 방향·얼굴 구조·기본 크기를 바꾸지 않는다. 실제 넉백 이동은 게임 코드와 구분한다.
- **사망:** 몸의 응집이 풀리는 짧은 변형과 소멸. 복잡한 폭발·입자 효과는 본체 스프라이트에 미리 합치지 않는다.
- 공격 피해 또는 투사체 생성 시점은 **접촉 프레임이나 발사 프레임**으로 지정한다. 공격 애니메이션의 끝을 타격 시점으로 취급하지 않는다. 복귀 완료는 별도 종료 시점이다. 이는 제작 기준이며 실제 스크립트를 자동 수정하지 않는다.
- 애니메이션 전체에서 캔버스 크기·기준 피벗·크기·시점을 유지한다. 접지 동작의 기준선과 의도된 변형을 구분한다. 공격이 뻗는 구간까지 포함할 여백을 미리 확보한다.
- 각 적의 실제 구현에 필요한 경우에만 파츠를 나눈다. 한 덩어리로 충분한 적을 복잡한 리그로 분해하지 않는다.

## 첫 기준 적 — 밀림덩이

기본 바이러스 계열의 근접 적. 낮고 두툼한 비대칭 콩 모양의 살아 있는 덩어리다. 상체가 밑몸보다 왼쪽으로 조금 밀려 있어, 앞쪽은 둥글게 튀어나오고 뒤쪽에는 한 번의 단차가 생긴다. 두 부분은 부드러운 좁은 연결부로 이어져 있으며, 분리된 블록처럼 그리지 않는다. 이 밀림이 유일한 주된 데이터 오류다.

얼굴은 왼쪽 앞면에 점눈 두 개와 아주 짧은 선 입으로 배치한다. 기본 색은 회녹색 계열이다. 예시 팔레트는 외곽선 `#252B30`, 주색 `#7FA650`, 밝은 면 `#A9C776`, 어두운 면 `#536F3A`다. 모든 적을 이 색으로 칠하라는 규칙은 아니다.

발은 따로 붙이지 않는다. 넓은 밑몸이 눌리고 복원되며 미끄러진다. 대기 중에도 상체가 밀린 특징은 남긴다.

| 동작 | 밀림덩이의 첫 제작 분량 | 핵심 자세 |
| --- | --- | --- |
| 대기 | 2프레임, 반복 | 기본 → 살짝 눌림 → 기본 |
| 이동 | 4프레임, 반복 | 기본 → 앞부분 낮아짐 → 밑몸 압축 → 기본 복원 |
| 공격 | 4프레임, 비반복 | 뒤로 압축 → 상체를 왼쪽으로 뻗어 접촉 → 반동 → 기본 복귀 |
| 피격 | 1자세 | 타격 반대쪽으로 짧게 찌그러짐 |
| 사망 | 2프레임, 비반복 | 낮게 주저앉음 → 몸이 두세 조각으로 느슨하게 갈라짐; 이후 게임에서 제거 |

공격의 2번째 프레임을 접촉·타격 프레임으로 지정한다. 마지막 프레임은 대기 자세와 이어지게 한다. 동작의 실제 길이와 공격 주기는 스탯에 맞춰 Unity에서 정하며, 이미지 생성만으로 확정하지 않는다.

위 프레임 수는 **밀림덩이의 첫 제작 기준**이다. 적 25종 전체에 같은 프레임 수나 같은 공격을 강제하지 않는다. 원거리 적은 접촉 대신 실제 발사 자세에 타격 이벤트를 둔다.

## 다른 계열로 확장할 때

| 계열 | 외형·동작을 발전시킬 방향 |
| --- | --- |
| 기본 바이러스 | 몸 밀림·누락·처짐 중 하나로 구분. 몸 자체로 기본 공격 |
| 와이퍼 | 부드러운 몸 앞쪽에 평평한 삭제면을 통합. 준비 때 면을 압축하고 타격 때 펼침 |
| 웜 | 앞뒤로 이어진 부드러운 굴곡과 순차적인 압축·복원. 복제체는 원본 외형을 작게 재사용 |
| 랜섬웨어 | 본체를 감싸는 단순한 보호층. 보호층 유무가 읽히게 하고 큰 자물쇠 장식에 의존하지 않음 |
| 애드웨어 | 몸 가장자리의 접힌 막 또는 작은 탭 같은 돌출부 하나. 몸과 함께 펴지고 접히며 별도 UI 아이콘으로 변하지 않음 |

## 제작 순서와 검수

1. 한 적의 기본 자세를 먼저 결정한다. 첫 작업은 밀림덩이 한 마리다.
2. 실루엣과 얼굴을 승인한 뒤 그 기본 스프라이트를 동작 제작의 고정 참고로 사용한다.
3. 동작마다 별개의 적을 새로 디자인하지 않는다. 생성 프롬프트에 프레임별 변형과 고정 요소를 함께 적는다.
4. 실제 전투 화면 크기로 줄여 아군 도구·아이콘 옆에서 확인한다. 정체성·픽셀 밀도·외곽선 두께·명암 밀도가 맞는지 본다.
5. 기본/접촉/복귀 자세가 읽히고 원형이 유지되는지 확인한 뒤 다른 적으로 확장한다.
6. 이전 적 이미지나 이전 프롬프트를 새 디자인의 형태·얼굴 참고로 다시 넣지 않는다. 아군의 기존 외형과 규칙도 변경하지 않는다.
