# 색상별 물감 찍기

기존 색상별 공격 클립 세 개에 Brush의 Local Position 키를 추가했다. 기본 Paint_Attack의 현재 회전 동작을 복사하고, 타격 1.37초·종료 1.62초 이벤트를 유지했다.

- 빨강: 팔레트 오른쪽 위의 빨간 물감.
- 노랑: 팔레트 왼쪽 위의 노란 물감.
- 파랑: 팔레트 왼쪽의 파란 물감.
- 0.10초와 0.64초에 해당 물감을 찍고, 잠깐 들어 올린 뒤 0.95초에 기존 공격 위치로 돌아온다.
- 시작은 기본 붓이고, 첫 물감 접촉인 0.10초부터 해당 색상 붓으로 바뀐다.

기준 배치: Visual의 원점에 Palette_Static, Brush는 Local Position (0.746, 0.19, 0), Scale (1, 1, 1). 피벗은 사용자가 지정한 값으로 통일된 붓을 사용했다.

물감 색상 픽셀의 중심과 붓털 앞쪽 12% 영역의 중심으로 실제 접촉 위치를 계산했다. Unity Preview Scene에서 두 접촉 및 유지 포즈, 들어 올리기, 원위치 복귀, 색상 전환을 검증했다. 검증 수치는 verification.json에 있다. Paint-Dip-Preview.gif는 왼쪽부터 빨강·노랑·파랑이며 반복은 미리보기용이다.

기존 클립 파일을 직접 갱신했으므로 Override Controller를 다시 연결할 필요는 없다. 기본 공격 클립을 앞으로 수정하면 색상별 클립은 별도로 동기화해야 하며, 이번에 만든 위치 키는 각 색상 클립의 Brush / Position에서 수정한다. 일반 클립을 통째로 복사하면 색상별 위치 키도 덮어써지므로 주의한다.

수정 전 각 클립은 *.before.txt와 *.current-editor.json으로 백업했다. C# 및 씬 배치는 수정하지 않았다.
